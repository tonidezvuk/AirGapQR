# Code of Conduct

AirGapQR is an open-source project.

Contributors and participants are expected to communicate respectfully, focus on technical issues, and avoid harassment, threats, personal attacks, or discriminatory behavior.

Technical disagreement is welcome. Personal hostility is not.

Project discussions should remain focused on improving the software, documentation, testing, and security of AirGapQR.

Maintainers may remove or restrict participation when behavior repeatedly disrupts the project or creates an unsafe environment for contributors.
